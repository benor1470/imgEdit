# imgEdit

A simple, ad-free image editor for Android (Kotlin + Jetpack Compose).

- Open a picture, crop / stretch / rotate the whole canvas
- Add pictures and text as separate elements: move, scale, stretch, rotate, re-edit
- Free-hand drawing
- Export PNG / JPG, or save an editable project as a plain SVG file

## Getting the APK

Every push to `main` builds a debug APK with GitHub Actions and publishes it
under **Releases**. Download the newest `imgEdit-N.apk` on the phone and install it.
